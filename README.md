# Jobsnowonline

Job search made simple — a free job board and career tools.

**Find work →** [jobsnowonline.com](https://jobsnowonline.com)

## Open tools

- **[jobsnow-feed](https://github.com/jobsnowonline/jobsnow-feed)** — serverless job aggregator API pulling remote listings from public boards into one clean JSON feed (Cloudflare Workers + KV)
- **[cv-templates](https://github.com/jobsnowonline/cv-templates)** — free professional CV/resume templates in HTML, Markdown, JSON, LaTeX and plain text
- **[cv-score](https://github.com/jobsnowonline/cv-score)** — score your CV against a job description
- **[work-games](https://github.com/jobsnowonline/work-games)** — quick browser games that strengthen your job search — play in the Break Room
